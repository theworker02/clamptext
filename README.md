# clamptext

Clamp color text values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/clamptext/

## Install / run

```bash
git clone https://github.com/theworker02/clamptext.git
cd clamptext
node src/cli.js
node --test
```
